# PrivateProcureAI

PrivateProcureAI is a portfolio project for a multi-agent AI procurement and planning system.

It will transform a natural-language goal into a structured plan using:

- specialized AI agents;
- retrieval-augmented generation (RAG);
- deterministic budget and constraint validation;
- evaluation and iterative re-planning;
- user preferences and memory;
- cryptographically signed final results.

## Current status

Module 0 is in progress: repository setup, architecture, and development conventions.
